# Kerbal Space Program | Spacex Starship Telemetry

# Disclaimer: 

- This mod was TOTALLY created by using the free plan of Claude.ai ; I have no code experience for KSP and I 1000% admit it!
- I also try my best to avoid any kind of AI slop.

This mod add a telemetry for your flights with starship in Kerbal Space Program.
You can customise the data displayed for both Super Heavy and Starship, the differents mission events and more by using the "control panel" integrated (click on F10 or on the little button in the bottom right of your screen).

You can enable / disable the telemetry by clicking on the mod icon in the toolbar.
The telemetry stay enable after clicking F2.

# This mod has no dependencies and no unsupported mod.
